# 🥗 NutriVida — Landing Page para Nutricionista

Landing Page moderna, premium e responsiva desenvolvida para profissionais de nutrição. Focada em **conversão de visitantes em pacientes** através de agendamento via WhatsApp, formulário e contato direto.

## ✨ Visão Geral

Uma landing page de alto padrão inspirada em designs de empresas como Apple, Stripe e Airbnb. Desenvolvida com foco em **UX/UI premium**, **SEO otimizado** e **alta taxa de conversão**.

### 🎯 Objetivo

Converter visitantes em pacientes através de:
- 📅 Agendamento online
- 💬 Contato via WhatsApp
- 📋 Formulário de contato

---

## 🖥️ Seções da Página

| # | Seção | Descrição |
|---|-------|-----------|
| 1 | **Hero** | Headline forte, CTAs, indicadores de confiança e foto profissional |
| 2 | **Benefícios** | Cards modernos com ícones destacando diferenciais |
| 3 | **Sobre** | Foto, história, missão, especializações e certificações |
| 4 | **Áreas de Atuação** | 8 cards ilustrados (emagrecimento, hipertrofia, clínica, etc.) |
| 5 | **Como Funciona** | Timeline elegante com 4 passos |
| 6 | **Diferenciais** | Grid premium com 8 features do atendimento |
| 7 | **Depoimentos** | Cards com foto, avaliação e resultados de pacientes |
| 8 | **Antes e Depois** | Galeria com placeholders (conforme normas éticas do CFN) |
| 9 | **FAQ** | Accordion moderno com 6 perguntas frequentes |
| 10 | **Chamada Final** | CTA forte com botões de agendamento e WhatsApp |
| 11 | **Rodapé** | Contato, horários, redes sociais e CRN |

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/magalhaespaula46/Nutri-terra.git
```

2. Abra o `index.html` no navegador ou use um servidor local:
```bash
npx serve .
```

3. Personalize os dados:
   - Altere nome, CRN, telefone e endereço no `index.html`
   - Substitua as imagens em `assets/img/`
   - Atualize o link do WhatsApp
